How this maps to M3E + your existing code

One continuous scroll — the phone frame above scrolls: hero/chips/carousels on top, a sticky "Your library" header with M3 filter chips (Songs/Artists/Albums/Folders/♥ Liked), then the list. A soft scroll-hint pill bridges the two worlds.

Library chips = your existing tabs — the same data sources as today's pill switcher, restyled as M3 filter chips with the primaryContainer active state. "Liked" joins as a first-class tab (backed by MediaStore ratings or a favorites flag).

M3 navigation bar — the bottom pill switcher graduates to a proper M3 nav bar (Home / Search / Songs / Settings); the top pill switcher becomes the in-page chips.

Breathe + shapes — the hero card tints from current-song art with the existing 220ms palette breathe; 20–28dp cookie radii match the player artwork.
